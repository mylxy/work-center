# Triage 标签

工程技能使用五种标准 triage 角色。下表将这些角色映射到本仓库 issue tracker 中的实际标签。

| 工程技能中的角色 | Tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 AFK agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某种角色时，应使用本表对应的实际标签字符串。

如果仓库以后改用其他标签词汇，请编辑中间一列。
